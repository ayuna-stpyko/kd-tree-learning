# 練習: 1 次元の最近傍点

kd-tree に入る前の練習問題です。判定結果だけが返り、順位表には載りません。

## 問題

数直線上に N 個の点があります。点には 1 から N までの番号が付いています。

Q 個のクエリに答えてください。各クエリでは番号 i が与えられるので、**点 i 以外の点のうち、点 i に最も近い点の番号**を出力してください。最も近い点が複数あるときは、そのうち**番号が最小の点**を出力してください。

点 i と同じ座標の別の点がある場合、その点までの距離は 0 です。

### 入力

本問題の D = 1 の場合と同じ形式です。

```
N 1
x_1
...
x_N
Q
i_1
...
i_Q
```

### 出力

Q 行出力してください。j 行目には、クエリ i_j の答えの番号を出力してください。

### 制約

- 2 ≤ N ≤ 2 × 10^5
- 座標はすべて整数で、絶対値は 10^8 以下
- 1 ≤ Q ≤ N
- 1 ≤ i_j ≤ N (同じ番号が複数回出ることがあります)

### 入出力例

入力 (`samples/01.in`)

```
6 1
5
1
8
5
-3
10
6
1
2
3
4
5
6
```

出力 (`samples/01.out`)

```
4
1
6
1
2
3
```

- 点 1 と点 4 は同じ座標なので、互いに相手が答えになります。
- 点 2 から見ると、点 1・点 4・点 5 がどれも距離 4 で最も近いので、番号が最小の 1 が答えです。

## ヒント

全部の点との距離を調べると O(NQ) で、大きいケースでは間に合いません。O(N log N) で解けます。
