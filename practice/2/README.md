# 練習: 2 次元の最近傍点 (マンハッタン距離)

kd-tree の練習問題です。判定結果だけが返り、順位表には載りません。本問題との違いは、**次元が 2 に決まっていること**と、**距離がマンハッタン距離**であることです。

## 問題

平面上に N 個の点があります。点には 1 から N までの番号が付いています。

Q 個のクエリに答えてください。各クエリでは番号 i が与えられるので、**点 i 以外の点のうち、点 i にマンハッタン距離で最も近い点の番号**を出力してください。最も近い点が複数あるときは、そのうち**番号が最小の点**を出力してください。

点 (x, y) と点 (x', y') のマンハッタン距離は |x − x'| + |y − y'| です。点 i と同じ座標の別の点がある場合、その点までの距離は 0 です。

### 入力

本問題の D = 2 の場合と同じ形式です。

```
N 2
x_1 y_1
...
x_N y_N
Q
i_1
...
i_Q
```

### 出力

Q 行出力してください。j 行目には、クエリ i_j の答えの番号を出力してください。

### 制約

- 2 ≤ N ≤ 10^5
- 座標はすべて整数で、絶対値は 10^8 以下
- 1 ≤ Q ≤ N
- 1 ≤ i_j ≤ N (同じ番号が複数回出ることがあります)

### 入出力例

入力 (`samples/01.in`)

```
5 2
0 0
3 0
2 2
-1 2
5 5
5
1
2
3
4
5
```

出力 (`samples/01.out`)

```
2
1
2
1
3
```

- 点 1 から見ると、点 2 (距離 3+0) と点 4 (距離 1+2) がどちらも距離 3 で最も近いので、番号が小さい 2 が答えです。ユークリッド距離なら点 4 (距離 √5) だけが最も近くなります。
- 点 2 から見ると、点 1 と点 3 がどちらも距離 3 なので 1 が答えです。

## ヒント

全部の点との距離を調べると O(NQ) で、大きいケースでは間に合いません。O(N log N) 程度で解けます。
