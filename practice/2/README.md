# 練習: 2 次元の最近傍点 (マンハッタン距離)

## 問題

$N$ 人の人が二次元平面上にいます。$i$ 人目の座標は $(X_i, Y_i)$ です。$Q$ 個クエリが与えられるので、それぞれに答えてください。

$Q$ 個のクエリに答えてください。各クエリでは番号 $m_i$ が与えられるので、人 $m_i$ 以外の人のうち、人 $m_i$ にマンハッタン距離で最も近い人の番号を出力してください。最も近い人が複数あるときは、そのうち**番号が最小の人**を出力してください。

人 $a$ と人 $b$ のマンハッタン距離は $|X_a - X_b| + |Y_a - Y_b|$ です。

### 入力

本問題の $D = 2$ の場合と同じ形式です。

```
N 2
X_1 Y_1
...
X_N Y_N
Q
m_1
...
m_Q
```

### 出力

$Q$ 行出力してください。$i$ 行目には、クエリ $m_i$ の答えの番号を出力してください。

### 制約

- $2 \leq N \leq 10^5$
- $|X_i| \leq 10^8$
- $|Y_i| \leq 10^8$
- $1 \leq Q \leq N$
- $1 \leq m_i \leq N$ (同じ番号が複数回出ることがあります)
- 入力はすべて整数

### 入出力例

入力 (`samples/01.in`)

```
5 2
0 0
3 0
2 2
-1 2
5 5
5
1
2
3
4
5
```

出力 (`samples/01.out`)

```
2
1
2
1
3
```

- 人 1 から見ると、人 2 (距離 $3 + 0$) と人 4 (距離 $1 + 2$) がどちらも距離 3 で最も近いので、番号が小さい 2 が答えです。ユークリッド距離なら人 4 (距離 $\sqrt{5}$) だけが最も近くなります。
- 人 2 から見ると、人 1 と人 3 がどちらも距離 3 なので 1 が答えです。
